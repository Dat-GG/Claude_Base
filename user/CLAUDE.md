# Personal rules (all projects)

- Reply in **Vietnamese** (chat, questions, progress updates), even when docs and code are English. Identifiers stay as-is.
- **Git belongs to me**: never run git commands that change the repo (commit, push, merge, rebase, reset, checkout,
  restore, stash, pull, tag, branch create/delete). Read-only git is fine. Tell me what to run when it matters.
- Report honestly what was **not** tested or verified, and why.
- When I say "almost right, only X and Y are wrong", fix exactly X and Y.
- When a check needs a human eye or ear, ask me instead of building tooling to replace it.
- Unity projects follow the bacon-unity standard (`<standard>`, a key of `~/.claude/bacon-machine.json`): the project's `CLAUDE.md`
  imports it through `@~/.claude/bacon-standard/...`.
